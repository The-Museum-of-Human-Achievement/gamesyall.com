A solo-developed game originally made for Global Game Jam 2026 about using negative space to create art. Use various household objects to form paintings in unconventional ways and match examples of art as closely as possible. 

Each level will feature rooms within a mysterious house that reveal more about these paintings and where you are. Complete each level as you gain access to more tools and the examples get more difficult.
